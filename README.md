# 💰 FinMate AI

### AI-Powered Personal Finance Assistant

FinMate AI is an AI-powered personal finance assistant that helps users understand their spending, identify recurring subscriptions, detect unusual transactions, and generate personalized financial insights from transaction data.

---

## 🚀 Features

- 📂 Upload transaction data through CSV
- 💰 Analyze total spending
- 📊 View spending by category
- 📅 Analyze monthly spending patterns
- 🔄 Detect recurring subscriptions
- ⚠️ Identify unusual spending
- 💡 Generate personalized financial insights
- 🤖 Ask FinMate questions about your spending
- 📋 View complete transaction history
- 🇮🇳 Indian Rupee (₹) friendly financial dashboard
